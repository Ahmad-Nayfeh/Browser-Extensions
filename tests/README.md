# الاختبارات التلقائية

اختبارات تشغّل كل إضافة في متصفح Chromium حقيقي وتتأكد أنها تعمل. لا تحتاج أن تختبر بنفسك.

## تعمل وحدها على GitHub
في كل مرة يتغير فيها الكود، يشغّل GitHub الاختبارات كلها (تبويب **Actions** في المستودع)، و**كل اثنين** يضيف اختبارات على مواقع حقيقية، ليكتشف إن غيّر موقع شيئاً يكسر إضافة.
- ✅ أخضر = كل شيء يعمل
- ❌ أحمر = اضغط عليه لترى أي اختبار فشل ولماذا

وتستطيع تشغيلها متى شئت: **Actions ← Tests ← Run workflow**.

## ماذا تختبر؟
28 اختباراً تغطي الإضافات الـ16. أمثلة:

| الإضافة | ماذا يُختبر |
|---|---|
| Shield | حظر الإعلانات والمتتبعات، إخفاء مربعات الإعلانات، القائمة المسموحة، العدّاد، أداة الاختيار، YouTube (حذف بيانات الإعلان، التخطي، إعادة السرعة)، وعلى موقع حقيقي: نقص الطلبات |
| Sleepy Tabs | تنويم التبويبات القديمة فقط، الاستثناءات، الحفظ والإغلاق |
| Snap | الصورة الكاملة دون تكرار العنوان الثابت، القص، التراجع، صحة ملفات PNG/JPG/PDF |
| No Cookies | الضغط على "Reject all"، فك قفل التمرير، احترام استثناءات المواقع |
| Reel | التسجيل مع الكاميرا، الإيقاف المؤقت، القص، تسجيل جزء من الشاشة، أداة الرسم |
| Lexi | الترجمة العربية، التعريف، الحفظ، المراجعة المتباعدة |
| Trace | التقاط الأخطاء والطلبات الفاشلة والمشاكل البصرية، **وعدم** الإنذار الكاذب، وإخفاء كلمات المرور |
| Blueprint | الموقع كاملاً، واجهة الخادم، إخفاء الأسرار والإيميلات، صفحة واحدة لكل قالب، الصور بلا قطع |

الاختبارات تستخدم **مواقع وهمية** تُبنى داخل الاختبار (فيها إعلانات وأخطاء ونوافذ كوكيز…)، فتعطي نفس النتيجة كل مرة ولا تحتاج إنترنت. أما اختبارات المواقع الحقيقية فمنفصلة.

## تشغيلها على جهازك (اختياري)
تحتاج [Node.js](https://nodejs.org) 22 أو أحدث:
```bash
cd tests
npm ci
npx playwright install chromium
```
ثم من المجلد الرئيسي:
```bash
node tests/run.js
```
- إضافة واحدة فقط: `node tests/run.js 04` أو `node tests/run.js shield`
- مع المواقع الحقيقية: `node tests/run.js --real`
- اختبارات المسجّل (Reel) تحتاج شاشة: على Windows و Mac تعمل مباشرة، وعلى خادم Linux استخدم `xvfb-run -a node tests/run.js`

## الملفات
| الملف | الوظيفة |
|---|---|
| `run.js` | يشغّل الاختبارات ويطبع ✅ / ❌ |
| `lib.js` | أدوات مشتركة: تشغيل المتصفح مع الإضافات، المواقع الوهمية، قراءة ملفات ZIP |
| `NN-*.test.js` | اختبارات كل إضافة |
| `fixtures/` | ملف فيديو صغير للاختبار |
