# إضافات Chrome الخاصة بي

16 إضافة لمتصفح Chrome، مصنوعة من الصفر: بدون مكتبات خارجية، وبدون حسابات، وكل بياناتك تبقى على جهازك.

| # | الإضافة | ماذا تفعل |
|---|---|---|
| 01 | [Shield](extensions/01-ad-blocker) | يحظر الإعلانات والمتتبعات في كل المواقع، ومنها YouTube |
| 02 | [Sleepy Tabs](extensions/02-tab-suspender) | ينوّم التبويبات غير المستخدمة لتوفير الذاكرة |
| 03 | [Focus](extensions/03-focus-blocker) | يحظر المواقع المشتتة، أو يحدد لها وقتاً يومياً |
| 04 | [Speedy](extensions/04-video-speed) | يغيّر سرعة أي فيديو من لوحة المفاتيح |
| 05 | [Clean Tube](extensions/05-youtube-cleaner) | يخفي Shorts والتوصيات والتعليقات في YouTube |
| 06 | [Snap](extensions/06-page-screenshot) | لقطة شاشة للصفحة كاملة مع محرر |
| 07 | [Restyle](extensions/07-site-css) | CSS خاص بك لأي موقع |
| 08 | [Night](extensions/08-dark-mode) | وضع داكن خفيف لكل المواقع |
| 09 | [No Cookies](extensions/09-cookie-dismiss) | يرفض نوافذ الكوكيز تلقائياً |
| 10 | [Later](extensions/10-read-later) | اقرأ لاحقاً + ملاحظات على الصفحات |
| 11 | [Reel](extensions/11-screen-recorder) | تسجيل الشاشة كاملة أو نافذة أو تبويب، مع المايك والكاميرا والرسم |
| 12 | [Why?](extensions/12-tab-reasons) | يتذكر لماذا فتحت كل تبويب، ويذكّرك |
| 13 | [Lexi](extensions/13-word-learner) | ترجمة الكلمات الإنجليزية بالعربي + مراجعة ذكية لحفظها |
| 14 | [Copy as Markdown](extensions/14-copy-markdown) | ينسخ أي صفحة كـ Markdown، والمعادلات تبقى بصيغة LaTeX |

في مجلد كل إضافة ملف `README.md` يشرحها بالتفصيل.

## التثبيت

### الخطوة 1: التحميل (مرة واحدة)
1. في أعلى صفحة المستودع على GitHub اضغط الزر الأخضر **Code** ثم **Download ZIP**.
2. فك الضغط في **مكان دائم**، مثلاً: `Documents\Browser-Extensions`

> ⚠️ Chrome يقرأ الإضافات من هذا المجلد مباشرة، فلا تحذفه. وإذا نقلته لاحقاً، احذف الإضافات من `chrome://extensions` وأضفها من المكان الجديد، **وبياناتك تبقى**: كل إضافة لها رقم تعريف ثابت (`key`) لا يتغير بتغيّر مكان المجلد.

### الخطوة 2: تفعيل وضع المطوّر (مرة واحدة)
1. اكتب في شريط العنوان: `chrome://extensions` واضغط Enter.
2. فعّل **Developer mode** (الزر أعلى اليمين).

### الخطوة 3: إضافة الإضافات

**إضافة واحدة فقط:**
اضغط **Load unpacked** ← ادخل مجلد `extensions` ← اختر مجلد الإضافة (مثلاً `04-video-speed`) ← **Select Folder**.

**كل الإضافات:**
كرر نفس الخطوة لكل مجلد داخل `extensions`، أي 16 مرة (حوالي دقيقتين).

> Chrome لا يسمح بتحميل كل الإضافات بضغطة واحدة: يجب اختيار مجلد كل إضافة وحده، أي المجلد الذي فيه ملف `manifest.json`. اختيار المجلد الكبير `extensions` كله **لن ينجح**.

### الخطوة 4: تثبيت الأيقونات
اضغط أيقونة قطعة البازل 🧩 بجانب شريط العنوان، ثم الدبوس 📌 بجانب الإضافات التي تستخدمها كثيراً.

## التحديث لاحقاً
1. حمّل ZIP جديداً.
2. **استبدل الملفات داخل نفس المجلد القديم** (لا تضعها في مكان جديد).
3. في `chrome://extensions` اضغط زر التحديث ⟳ على كل إضافة.

بياناتك وإعداداتك تبقى كما هي.

**تحديث قوائم الإعلانات والكوكيز** (للإضافتين 01 و 09، يُنصح به كل شهر تقريباً)، إذا كان Python مثبتاً عندك:
```bash
python3 tools/build_filters.py
```

## مشاكل شائعة

| المشكلة | الحل |
|---|---|
| "Manifest file is missing" | اخترت المجلد الخطأ. اختر مجلد الإضافة نفسه، مثلاً `01-ad-blocker`، لا `extensions` |
| الإضافة لا تعمل في صفحة معينة | صفحات `chrome://` و Chrome Web Store ممنوعة على كل الإضافات |
| اختصار لوحة مفاتيح لا يعمل | غيّره أو فعّله من `chrome://extensions/shortcuts` |
| أريد إيقاف إضافة مؤقتاً | أطفئ مفتاحها في `chrome://extensions`، دون حذفها |

## لماذا هي خفيفة على الجهاز؟
- كل إضافة **تعمل فقط عند حدث** (ضغطة، تبديل تبويب، تشغيل فيديو)، ثم تنام. لا توجد مؤقتات تعمل كل ثانية.
- الحظر يتم بمحرك Chrome نفسه (`declarativeNetRequest`)، والإخفاء بـ CSS يطبقه المتصفح.
- الأكواد الثقيلة (المحررات، أداة الرسم، المحوّلات) **لا تُحمَّل إلا عند استخدامها**.
- Shield يقلل الحمل فعلاً: في اختبار حقيقي نزلت طلبات صفحة The Verge من 725 إلى 187، وصفحة Speedtest من 1361 إلى 42.

## مجلد `tools` (للتطوير فقط)
| الملف | الوظيفة |
|---|---|
| `build_filters.py` | يحوّل قوائم EasyList وغيرها إلى قواعد Chrome |
| `make_icons.py` | يرسم الأيقونات (يحتاج Pillow) |
| `shared/ui.css` + `sync_shared.sh` | التصميم المشترك: عدّله ثم شغّل السكربت لنسخه لكل الإضافات |
