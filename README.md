# إضافات Chrome الخاصة بي

عشر إضافات لمتصفح Chrome، كلها مصنوعة من الصفر، بدون أي مكتبات خارجية، وبدون حسابات أو سحابة. كل البيانات تبقى على جهازك.

| # | الإضافة | ماذا تفعل باختصار |
|---|---|---|
| 01 | [**Shield**](extensions/01-ad-blocker) | مانع إعلانات ومتتبعات في كل المواقع، ومنها YouTube |
| 02 | [**Sleepy Tabs**](extensions/02-tab-suspender) | تنويم التبويبات غير المستخدمة لتوفير الذاكرة، وحفظ مجموعات التبويبات |
| 03 | [**Focus**](extensions/03-focus-blocker) | حظر المواقع المشتتة، أو تحديد وقت يومي لها |
| 04 | [**Speedy**](extensions/04-video-speed) | التحكم بسرعة أي فيديو من لوحة المفاتيح |
| 05 | [**Clean Tube**](extensions/05-youtube-cleaner) | إخفاء Shorts والتوصيات والتعليقات في YouTube |
| 06 | [**Snap**](extensions/06-page-screenshot) | لقطة شاشة للصفحة كاملة مع محرر (قص، رسم، تمويه) وتصدير PNG/JPG/PDF |
| 07 | [**Restyle**](extensions/07-site-css) | اكتب CSS خاصاً بك لأي موقع |
| 08 | [**Night**](extensions/08-dark-mode) | وضع داكن خفيف لكل المواقع |
| 09 | [**No Cookies**](extensions/09-cookie-dismiss) | رفض نوافذ الكوكيز تلقائياً وإخفاؤها |
| 10 | [**Later**](extensions/10-read-later) | حفظ الصفحات للقراءة لاحقاً، وملاحظات على أي صفحة |

كل مجلد فيه ملف `README.md` يشرح الإضافة بالتفصيل.

## طريقة التثبيت (مرة واحدة لكل إضافة)

1. حمّل المستودع على جهازك: زر **Code ← Download ZIP**، ثم فك الضغط. أو استخدم `git clone`.
2. افتح في Chrome العنوان: `chrome://extensions`
3. فعّل **Developer mode** (الزر أعلى اليمين).
4. اضغط **Load unpacked** واختر مجلد الإضافة، مثلاً `extensions/01-ad-blocker`.
5. كرر الخطوة 4 لكل إضافة تريدها.
6. ثبّت الأيقونات التي تستخدمها كثيراً: أيقونة قطعة البازل 🧩 ← رمز الدبوس 📌.

**ملاحظات مهمة:**
- **لا تحذف أو تنقل المجلد** بعد التثبيت، فـ Chrome يقرأ الإضافة منه مباشرة.
- **بعد تعديل أي ملف** اضغط زر التحديث ⟳ على بطاقة الإضافة في `chrome://extensions`.
- الإضافات المحمّلة بهذه الطريقة لا تتحدث تلقائياً، فهي لا تتغير إلا إذا غيرتها أنت. هذه ميزة أمان: لا يستطيع أحد أن "يشتريها" ويضع فيها كوداً خبيثاً.

## لماذا هي خفيفة على الجهاز؟

صُممت كل إضافة لتعمل فقط عند الحاجة:

| المبدأ | أين استُخدم |
|---|---|
| **Service worker** ينام عندما لا يوجد حدث (Manifest V3) | كل الإضافات |
| **declarativeNetRequest**: Chrome نفسه يطبق قواعد الحظر بكود C++ سريع، دون أن يمر كودنا على كل طلب | Shield، Focus |
| **CSS بدل JavaScript**: المتصفح يخفي العناصر بنفسه، لا حلقات ولا مراقبة مستمرة | Shield، Clean Tube، No Cookies، Night، Restyle |
| **فلتر GPU واحد** بدل تحليل ألوان الصفحة | Night |
| **لا مؤقتات تعمل كل ثانية**: الاعتماد على أحداث (تبديل تبويب، تشغيل فيديو، ضغطة زر) | Focus، Speedy، Sleepy Tabs |
| **الصلاحيات الدنيا**: مثلاً `activeTab` بدل الوصول الدائم لكل المواقع | Snap |

Shield يقلل الحمل فعلاً. في اختبار حقيقي نزل عدد الطلبات في صفحة The Verge من **725 إلى 187**، وفي Speedtest من **1361 إلى 42**.

## الأدوات (مجلد `tools`)

| الملف | الوظيفة |
|---|---|
| `build_filters.py` | يحمّل قوائم الفلترة (EasyList، EasyPrivacy، Peter Lowe، قائمة الكوكيز) ويحوّلها إلى قواعد Chrome |
| `make_icons.py` | يرسم أيقونات الإضافات (يحتاج Pillow) |
| `shared/ui.css` + `sync_shared.sh` | التصميم المشترك لكل النوافذ: عدّل الملف ثم شغّل السكربت لنسخه لكل الإضافات |

**تحديث قوائم الإعلانات والكوكيز** (يُنصح به كل شهر تقريباً):

```bash
python3 tools/build_filters.py
```

ثم اضغط ⟳ على Shield و No Cookies في `chrome://extensions`.
