# 03 · Focus: حظر المواقع المشتتة

## ماذا تفعل؟
لكل موقع تختار واحداً من وضعين:
- **Block always:** محظور دائماً.
- **Limit to N min/day:** مسموح لعدد دقائق في اليوم، ثم يُحظر حتى منتصف الليل.

عند فتح موقع محظور تظهر صفحة "Stay focused 🎯" بدلاً منه.

## كيف تعمل؟
- **الحظر:** قاعدة إعادة توجيه (redirect) لكل موقع يطبقها Chrome نفسه. لا يوجد أي كود داخل الصفحات.
- **حساب الوقت:** الوقت يُحسب فقط إذا تحققت ثلاثة شروط معاً:
  1. الموقع هو التبويب النشط.
  2. نافذة Chrome في المقدمة.
  3. أنت لست خاملاً (لم تترك الجهاز أكثر من دقيقة).

  لا يوجد عدّاد يعمل كل ثانية. الإضافة تسجل **لحظة البداية** فقط، وعند أي تغيير (تبديل تبويب أو نافذة أو خمول) تحسب الفرق. ويُضبط منبّه واحد على لحظة انتهاء الرصيد بالضبط.
- عند انتهاء الرصيد تُعاد تحميل التبويبات المفتوحة لذلك الموقع فتظهر صفحة الحظر فوراً.
- الرصيد يتجدد عند منتصف الليل (بتوقيت جهازك).

## الاستخدام
افتح الموقع المشتت ← اضغط أيقونة Focus ← اختر **Block always** أو **Limit to** مع عدد الدقائق.
الحذف من القائمة ممكن، لكنه يسألك سؤالاً قبل الحذف 😉.

## ملاحظة
الحظر يشمل النطاقات الفرعية أيضاً: حظر `youtube.com` يحظر `m.youtube.com`.
