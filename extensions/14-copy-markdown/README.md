# 14 · Copy as Markdown

## ماذا تفعل؟
تنسخ أي جزء من صفحة، أو المقال كله، بصيغة **Markdown** نظيفة وجاهزة لملاحظاتك (Colab، Obsidian، Notion، GitHub…).

ما يُحوَّل بشكل صحيح:
| في الصفحة | في Markdown |
|---|---|
| العناوين | `#`, `##`, … |
| عريض / مائل / مشطوب | `**x**`, `*x*`, `~~x~~` |
| الروابط والصور | `[نص](رابط)`، والروابط النسبية تصبح كاملة |
| القوائم (والمتداخلة) | `-` و `1.` |
| **الجداول** | جداول GitHub (`| a | b |`) |
| **الكود** | ```` ```python ```` مع اسم اللغة إن وُجد |
| الاقتباسات | `>` |
| **المعادلات** | **LaTeX**: `$E=mc^2$` داخل السطر، و `$$...$$` في سطر مستقل |

المعادلات تعمل مع: **Wikipedia**، و**KaTeX**، و**MathJax 2 و 3** (أي معظم المواقع العلمية والتعليمية).

## الاستخدام
| الطريقة | ماذا يحدث |
|---|---|
| حدد نصاً ← زر يمين ← **Copy selection as Markdown** | ينسخ التحديد |
| زر يمين في أي مكان ← **Copy page as Markdown** | ينسخ المقال كله |
| `Alt+Shift+M` | التحديد إن وُجد، وإلا المقال كله |
| أيقونة الإضافة | معاينة قبل النسخ + **Download .md** |

خيار **Title & link** يضيف عنوان الصفحة ورابطها في الأعلى، لتعرف لاحقاً من أين أخذت النص.

## في وضع "المقال كله"
تحذف الإضافة القوائم والإعلانات والتذييل وروابط [edit] وأرقام المراجع [1]، وتأخذ المحتوى الرئيسي فقط.

## الخفة
لا يوجد أي كود في صفحاتك حتى تطلب النسخ: المحوّل يُحقن لحظة الاستخدام فقط.
