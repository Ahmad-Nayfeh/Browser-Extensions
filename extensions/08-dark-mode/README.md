# 08 · Night: وضع داكن خفيف

## ماذا تفعل؟
تحوّل كل المواقع الفاتحة إلى داكنة، وتتخطى تلقائياً المواقع الداكنة أصلاً.

## الاستخدام
| الخيار | المعنى |
|---|---|
| المفتاح أعلى النافذة | تشغيل أو إيقاف لكل المواقع |
| Default / Always dark / Never | اختيار خاص بالموقع الحالي |
| `Alt+Shift+D` | تبديل سريع للموقع الحالي |
| Brightness / Contrast | السطوع والتباين |
| Warm (sepia) | لون أدفأ، أريح للعين ليلاً |
| Skip sites that are already dark | لا تقلب المواقع الداكنة أصلاً |

## كيف تعمل؟ ولماذا هي أخف من Dark Reader؟
- **Dark Reader** (في وضعه الأساسي) يقرأ كل ألوان كل عنصر ويحسب لها ألواناً جديدة، ويراقب الصفحة باستمرار. لهذا يبطئ المواقع الكبيرة.
- **Night** تضع **فلتراً واحداً** على الصفحة كلها: `invert(1) hue-rotate(180deg)`. كرت الشاشة (GPU) يعكس الألوان، و`hue-rotate` يعيد الأحمر أحمر والأزرق أزرق. ثم تُعكس الصور والفيديو مرة ثانية فتظهر بألوانها الطبيعية.
- الكود الوحيد الذي يعمل: قراءة الإعدادات، وفحص لون خلفية الصفحة **مرة واحدة** لمعرفة هل الموقع داكن أصلاً.

## حدود (ثمن الخفة)
- الشعارات والأيقونات التي هي **صور داكنة بخلفية شفافة** تبقى داكنة على الخلفية الداكنة فيصعب رؤيتها، مثل شعار Wikipedia.
- الخلفيات المرسومة بـ CSS gradients تنقلب ألوانها.
- إذا لم يعجبك شكل موقع معين: **Never** لذلك الموقع.
