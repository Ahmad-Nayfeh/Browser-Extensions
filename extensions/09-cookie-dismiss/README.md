# 09 · No Cookies: إزالة نوافذ الكوكيز

## ماذا تفعل؟
1. **ترفض تلقائياً:** في أشهر منصات الموافقة تضغط **"Reject all"** بدلاً منك. الرفض أفضل لخصوصيتك من القبول، لأن الموقع لا يحق له تتبعك.
   المنصات المدعومة: OneTrust، Cookiebot، Didomi، Quantcast، Usercentrics، TrustArc، CookieYes، Complianz، Osano، iubenda، Borlabs، Klaro، Termly، Sourcepoint، Google/YouTube consent.
2. **تخفي الباقي:** باستخدام قائمة EasyList Cookie (نحو 15,000 قاعدة عامة و17,000 موقع).
3. **تفتح التمرير:** بعض النوافذ تقفل تمرير الصفحة، فتعيده الإضافة بعد الرفض.

عند الرفض الناجح تظهر ✓ خضراء على الأيقونة.

## الاستخدام
- **Active on this site:** أطفئه إذا تعطل موقع، مثلاً زر لا يعمل أو صفحة فارغة.
- **Click "Reject all" automatically:** أطفئه إذا أردت الإخفاء فقط دون ضغط أي زر.

## كيف تبقى خفيفة؟
- الإخفاء CSS يطبقه المتصفح (بنفس مبدأ Shield).
- سكربت الرفض يراقب الصفحة **15 ثانية كحد أقصى** ثم يتوقف نهائياً، ويتوقف فوراً بعد الرفض. ولا يفحص الصفحة أكثر من مرة في كل إطار (frame) مهما كثرت التغييرات.

## ملاحظات
- إخفاء النافذة دون رفض يعني أن الموقع **لم يحصل على موافقتك**. معظم المواقع الأوروبية تتعامل مع ذلك كرفض.
- مواقع كثيرة لا تعرض نوافذ كوكيز أصلاً خارج أوروبا.
- تحديث القائمة: `python3 tools/build_filters.py cookies`
