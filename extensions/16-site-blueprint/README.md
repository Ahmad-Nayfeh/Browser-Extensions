# 16 · Blueprint: تصدير تصميم أي موقع بالكامل

## الفكرة
أعجبك تصميم موقع وتريد أن يصبح موقعك بنفس الأسلوب؟ افتح الموقع واضغط **Analyze**، فتحصل على **ملف ZIP** فيه:
1. **ملف Markdown** فيه كل شيء عن الواجهة الأمامية للموقع، **وواجهة الخادم**
2. **صور كاملة لكل صفحة**، مهما كان طولها

أعطِ الملف لـ Claude: *"Restyle my site to match this design."*

## الاستخدام
1. افتح الموقع، ثم اضغط أيقونة Blueprint (أو `Alt+Shift+B`).
2. اختر:
   - **This page only**: هذه الصفحة فقط
   - **The whole site, up to N pages**: الموقع كاملاً (حتى 50 صفحة). Blueprint يفتح الصفحات **وحده** في نفس التبويب، صفحات القائمة الرئيسية أولاً، ثم يعود لصفحتك. انتظر فقط، والتقدم يظهر على الأيقونة (مثلاً `3/10`).
3. اضغط **Analyze**، فتفتح صفحة النتيجة ← **Download everything (.zip)**.

لا يفتح Blueprint أبداً روابط خطرة مثل **Log out** أو الحذف أو إلغاء الاشتراك.

## ماذا يحتوي الملف؟
| # | القسم | المحتوى |
|---|---|---|
| 1 | **Overview** | العنوان، الوصف، اللغة، **التقنيات المستخدمة** (React, Next.js, Vue, Tailwind, Bootstrap, WordPress…) |
| 2 | **Page structure** | كل قسم في الصفحة بالترتيب: حجمه، مكانه، تخطيطه (grid/flex، عدد الأعمدة، المسافات)، خلفيته، ومحتواه |
| 3 | **Design system** | الألوان ونسبة كل لون (خلفيات، نصوص، حدود، تدرجات)، الخطوط وأحجامها وأوزانها، تنسيق كل نوع نص (h1…h6، p، a، button…)، المسافات و**الوحدة الأساسية** (4 أو 8 بكسل)، عرض المحتوى، الزوايا، الظلال، **متغيرات CSS** |
| 4 | **Components** | الأزرار، الحقول، البطاقات، الروابط، القوائم، الشارات، الصور، الجداول، النوافذ المنبثقة. كل نوع مع **CSS الكامل** و**حالاته** (hover / focus / active / disabled) من ملفات الموقع نفسه |
| 5 | **Motion** | الانتقالات، الحركات (`@keyframes`)، العناصر الثابتة (sticky/fixed) |
| 6 | **Responsive** | نقاط التحويل (الجوال، التابلت…) وما يتغير في كل واحدة |
| 7 | **Assets** | ملفات الخطوط، الأيقونات، الشعار، الصور وأحجامها، الفيديو |
| 8 | **Behaviour** | النماذج وحقولها، القوائم المنسدلة، التبويبات، السلايدر، السكربتات الخارجية |
| 9 | **Content & accessibility** | تسلسل العناوين، روابط القوائم، مشاكل الوصول (صور بلا نص بديل…) |
| 10 | **Data & API** | **كل طلبات البيانات بين الموقع والخادم**: العنوان، الطريقة، ما أُرسل، و**شكل الرد بالتفصيل** (الحقول وأنواعها) مع مثال. الرموز السرية وكلمات المرور تُخفى تلقائياً (`•••`) |
| | **صفحات أخرى** (وضع الموقع كاملاً) | لكل صفحة: هيكلها، مكوناتها، صورها، نماذجها، والـ CSS الخاص بها فقط |
| A | **Full CSS** | **كل CSS الموقع**، بما فيه الملفات من نطاقات أخرى |
| B | **HTML skeleton** | هيكل الصفحة منظّفاً: بدون سكربتات، والنصوص الطويلة مختصرة |

## ملاحظات
- أثناء التحليل يظهر شريط Chrome *"Blueprint started debugging this browser"*. هذا طبيعي، فهو الطريقة التي تُلتقط بها الصور والبيانات، ويختفي في النهاية.
- الملف كبير عادة (من 500 KB إلى عدة MB للموقع كاملاً). Claude يتعامل مع هذا الحجم.
- استخدمه لأخذ **الأسلوب**، لا لنسخ شعارات أو محتوى موقع آخر.

## الخفة
لا يوجد أي كود في الصفحات حتى تضغط **Analyze**. الصفحة الواحدة تأخذ ثوانٍ، والموقع كاملاً (4 صفحات من Bootstrap) أخذ 28 ثانية.
