# 15 · Trace: مسجّل جلسات الاختبار

## الفكرة
تريد أن تختبر موقعك؟ شغّل Trace، وجرّب كل شيء في الموقع كما يفعل أي مستخدم، ثم أوقفه. تحصل على **ملف Markdown واحد** فيه كل ما حدث، تعطيه لـ Claude ليجد الأخطاء ويقترح الإصلاح.

## الاستخدام
1. افتح موقعك.
2. اضغط أيقونة Trace (أو `Alt+Shift+T`). يظهر **REC** على الأيقونة.
3. اختبر كل شيء: انقر، اكتب في الحقول، أرسل النماذج، انتقل بين الصفحات.
4. اضغط الأيقونة مرة ثانية، فتفتح صفحة التقرير.
5. اضغط **Download for Claude (.zip)**: ملف واحد فيه التقرير وكل الصور.
6. أعطِ الملف لـ Claude: *"Find the bugs in this test session and tell me how to fix them."*

التسجيل يستمر عند الانتقال بين صفحات الموقع، ويشمل التبويبات الجديدة التي يفتحها الموقع. وإذا أغلقت تبويب الاختبار يتوقف التسجيل وحده.

## ماذا يحتوي التقرير؟
| القسم | المحتوى |
|---|---|
| **For Claude** | تعليمات جاهزة لـ Claude: ماذا يفعل بالملف |
| **Summary** | الموقع، المدة، عدد الخطوات، عدد الأخطاء والطلبات الفاشلة |
| **Problems found** | كل خطأ مع **رقم الخطوة** التي سببته: أخطاء JavaScript (مع مكانها في الكود)، الطلبات الفاشلة (**مع رد الخادم**)، رسائل الخطأ التي ظهرت على الشاشة، الملفات المفقودة (404)، الطلبات البطيئة، **الطلبات المكررة** (نفس البيانات تُطلب مرتين = صفحة أبطأ)، النقر على أزرار معطّلة، و**المشاكل البصرية** |
| **📷 Screenshots** | **صورة للشاشة بعد كل خطوة**، ومكانها مذكور في الجدول الزمني، فيرى Claude ما رأيته أنت |
| **Timeline** | خطوة بخطوة: ماذا فعلت ← وماذا حدث بعدها (طلبات للخادم، عناصر ظهرت أو اختفت، أخطاء) |
| **All server requests** | جدول كل طلبات fetch/XHR: الطريقة، الرابط، الحالة، الوقت |
| **Console messages** | رسائل الـ console |
| **Appendix** | **كود HTML** لكل صفحة زرتها، منظّفاً |

مثال من التقرير:
```
6. [00:02] Submitted form form#login
   [00:02] ↳ ❌ POST /api/login → 401 (12 ms) — {"error":"Invalid credentials"}
   [00:04] ↳ Page changed: +1 / −0 elements; appeared: ⚠️ "Login failed: invalid email or password"
7. [00:04] Click button "Add to cart" (button#buy)
   [00:04] ↳ ❌ JS error: Uncaught TypeError: Cannot read properties of undefined (reading 'items')
```

## الفحص البصري التلقائي
بعد كل خطوة يفحص Trace الصفحة بحثاً عن مشاكل **لا تسبب أي خطأ تقني لكنها تبدو مكسورة**:

| الفحص | مثال |
|---|---|
| الصفحة أعرض من الشاشة | تمرير جانبي مزعج بسبب عنصر عريض |
| صور مكسورة | صورة لم تُحمَّل |
| أزرار مغطاة | زر لا يمكن الضغط عليه لأن عنصراً آخر فوقه |
| نص مقطوع | اسم منتج لا يتسع في مكانه |
| تباين ضعيف | نص رمادي فاتح على خلفية بيضاء يصعب قراءته |
| أزرار بلا نص | زر أيقونة بلا وصف |

ويتجاهل ما هو **مقصود في التصميم**، حتى لا يزعجك بإنذارات كاذبة: العناصر داخل صناديق التمرير، والمقتطفات المختصرة بـ "…"، والنصوص المخفية لقارئات الشاشة (`sr-only`). والصور المتطابقة لا تُحفظ مرتين.

## الخصوصية
- **كلمات المرور، أرقام البطاقات، CVV، الرموز (tokens) ورموز التحقق (OTP) تُخفى دائماً**: يُكتب فقط عدد الحروف.
- من الإعدادات (زر يمين على الأيقونة ← **Options**) تستطيع إخفاء **كل** ما تكتبه.
- يُسجَّل فقط التبويب الذي بدأت فيه، والتبويبات التي فتحها هو.

## الإعدادات
| الخيار | الافتراضي |
|---|---|
| إخفاء كل ما أكتبه | ❌ (كلمات المرور مخفية دائماً) |
| تسجيل `console.log` و `console.info` | ❌ (الأخطاء والتحذيرات تُسجَّل دائماً) |
| لقطة HTML لكل صفحة | ✅ |
| صورة للشاشة بعد كل خطوة | ✅ |
| الفحص البصري التلقائي | ✅ |

## نصيحة
Claude يصلح الخلل في **الكود المصدري لمشروعك**: التقرير يخبره أين الخلل وكيف يحدث، فأعطه مع التقرير ملفات مشروعك ليعدّلها مباشرة.

الخفة: لا يعمل شيء إلا أثناء التسجيل. بعد الإيقاف تُزال كل الأكواد من الصفحات.
