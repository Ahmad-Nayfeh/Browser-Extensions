# 11 · Reel: تسجيل الشاشة

## ماذا تفعل؟
تسجّل فيديو لـ:
- **الشاشة كاملة**: أي برنامج على اللابتوب (Excel، AutoCAD، سطح المكتب…)
- **نافذة واحدة** من أي برنامج
- **تبويب** واحد في Chrome

ويمكنك **تصغير Chrome** أثناء التسجيل والعمل في برامج أخرى.

بلا حد لطول الفيديو، وبلا علامة مائية، وبلا حساب. الفيديو يُحفظ في مجلد التنزيلات (Downloads).

## الاستخدام
1. اضغط أيقونة Reel (أو `Alt+Shift+R`)، فتفتح صفحة المسجّل.
2. اختر الإعدادات، ثم اضغط **Start recording**.
3. يسألك Chrome ماذا تريد أن تسجّل: **Entire screen** أو **Window** أو **Chrome tab**.
4. تظهر **نافذة تحكم صغيرة تبقى فوق كل البرامج** وفيها: الوقت، إيقاف مؤقت، الرسم، كتم المايك، إيقاف.
5. بعد الإيقاف تظهر صفحة النتيجة: شاهد الفيديو، **قص البداية والنهاية**، ثم **Save video**.

## الإعدادات
| الإعداد | المعنى |
|---|---|
| Quality | 720p / 1080p / 1440p / الحجم الأصلي |
| Frames per second | 15 (حجم أصغر) / 30 (عادي) / 60 (حركة ناعمة) |
| Record only part of the screen | بعد اختيار الشاشة تسحب مستطيلاً على الجزء الذي تريده فقط |
| 3-second countdown | عدّ تنازلي قبل البدء |
| Computer / tab sound | صوت الجهاز أو التبويب |
| Microphone | صوتك، مع اختيار الجهاز |
| Camera bubble | دائرة الكاميرا في زاوية الفيديو: المكان والحجم قابلان للتغيير |

## الرسم أثناء التسجيل
زر **Draw** في النافذة العائمة، أو `Alt+Shift+A`، يضع أدوات الرسم فوق **صفحة الويب** الحالية:

| الأداة | المفتاح |
|---|---|
| ↖ استخدام الصفحة عادياً | `1` |
| ✎ قلم | `2` |
| ▮ قلم تظليل | `3` |
| ➚ سهم | `4` |
| ▭ مستطيل | `5` |
| ◉ إضاءة حول الفأرة (يُظلم الباقي) | `6` |
| Cursor | دائرة صفراء حول مؤشر الفأرة |
| Fade | الرسومات تختفي وحدها بعد 3 ثوان |
| Clear | مسح الرسومات (`C`)، و `Esc` للإغلاق |

⚠️ **الرسم يعمل فوق صفحات الويب فقط**، لا فوق البرامج الأخرى. Chrome لا يسمح للإضافات بالرسم فوق سطح المكتب.

## حماية تسجيلك
الفيديو يُكتب على القرص **كل ثانية** أثناء التسجيل، فلا يمتلئ الـ RAM مهما طال. وإذا أغلقت الصفحة بالخطأ تجد زر **Open it** لاستعادة آخر تسجيل.

## ملاحظات
- **الصيغة:** MP4 إذا دعمها Chrome عندك (غالباً نعم)، وإلا WebM. MP4 يعمل في كل مكان تقريباً، و WebM يعمل في VLC والمتصفحات و YouTube، وقد لا يفتح في بعض مشغّلات Windows القديمة.
- **القص** يعيد تسجيل الجزء المختار، فيأخذ وقتاً **بطول الجزء نفسه**: قص دقيقة يأخذ دقيقة.
- **صوت النظام:** على Windows يُسجَّل صوت الجهاز كله عند اختيار الشاشة كاملة. على Mac قد لا يتوفر إلا صوت **التبويب**، حسب إصدار النظام. إن لم يظهر خيار الصوت في نافذة الاختيار فهذا هو السبب.
- **الخفة:** ترميز الفيديو عمل ثقيل بطبيعته، لكنه يحدث **أثناء التسجيل فقط**، ولا تستهلك الإضافة شيئاً باقي الوقت.
