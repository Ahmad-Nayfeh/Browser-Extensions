# 06 · Snap: لقطة شاشة كاملة مع محرر

## ماذا تفعل؟
| الزر | الاختصار | ماذا يلتقط |
|---|---|---|
| Full page | `Alt+Shift+S` | **الصفحة كلها** من أعلاها إلى أسفلها، في صورة واحدة |
| Visible area | `Alt+Shift+V` | ما تراه على الشاشة فقط |
| Select an area | | ما تراه، ثم يفتح المحرر وأداة القص جاهزة |

بعد الالتقاط يفتح **المحرر** في تبويب جديد.

## أدوات المحرر (كلها مجانية)
| الأداة | المفتاح | الاستخدام |
|---|---|---|
| ✂ Crop | `C` | اسحب لتحديد الجزء الذي تريد الإبقاء عليه |
| ▭ Box | `R` | مستطيل حول شيء مهم |
| ➚ Arrow | `A` | سهم يشير إلى شيء |
| ✎ Pen | `P` | رسم حر |
| T Text | `T` | اضغط في مكان واكتب نصاً |
| ▮ Highlight | `H` | تظليل شفاف مثل قلم الفسفوري |
| ▦ Blur | `B` | تمويه بيانات خاصة (أسماء، أرقام، إيميلات) |
| ↶ Undo | `Ctrl+Z` | تراجع (حتى 50 خطوة) |

**التصدير:** PNG (أفضل جودة)، JPG (حجم أصغر)، **PDF** (يُقسَّم تلقائياً إلى صفحات A4)، أو **Copy** للصق مباشرة في Teams أو Word أو الإيميل.

## كيف تعمل؟
- **Full page:** تستخدم واجهة المطورين في Chrome (`Page.captureScreenshot` مع `captureBeyondViewport`) لتلتقط الصفحة كلها **مرة واحدة**. الطريقة الشائعة (التمرير ثم لصق الصور) تكرر العناوين الثابتة في كل جزء، وهذه الطريقة لا تفعل ذلك.
- لهذا يظهر شريط أصفر للحظة يقول "Snap started debugging this browser". هذا طبيعي ويختفي وحده.
- الصورة تُحفظ مؤقتاً في IndexedDB على جهازك، وتُستبدل عند الالتقاط التالي.
- المحرر لا يعيد رسم الصورة الكبيرة أثناء السحب: المعاينة طبقة SVG خفيفة فوقها، والرسم الحقيقي مرة واحدة عند ترك الفأرة.

## حدود
- الصفحات الأطول من 30,000 بكسل تُقطع (تظهر رسالة).
- لا تعمل في صفحات `chrome://` و Chrome Web Store، فهذا منع من Chrome نفسه.
- بعض المواقع التي تُحمّل محتواها عند التمرير فقط (lazy loading) قد تظهر أجزاؤها السفلية فارغة. مرّر للأسفل مرة قبل الالتقاط.
