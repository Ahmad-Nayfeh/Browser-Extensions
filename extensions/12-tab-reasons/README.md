# 12 · Why?: لماذا فتحت هذا التبويب؟

## الفكرة
تفتح تبويباً لسبب ما، وبعد ساعة تجد 30 تبويباً ولا تتذكر لماذا فتحت نصفها. هذه الإضافة تحفظ السبب.

## كيف تعمل؟
1. **عند فتح تبويب جديد** يظهر شريط صغير أعلى الصفحة: *"Why is this tab open?"*. تكتب كلمتين (مثلاً "compare prices") وتضغط **Enter**. أو تتجاهله، فيختفي وحده بعد 15 ثانية.
2. **عندما تعود للتبويب بعد فترة** (15 دقيقة افتراضياً) يذكّرك:
   *"You opened this 2 h ago to: compare prices"*
   - **Done – close tab**: انتهيت، أغلقه.
   - **Still need it**: ما زلت أحتاجه.
   - **Edit**: عدّل السبب.
3. **نافذة الإضافة** تعرض كل تبويباتك المفتوحة مع أسبابها: اضغط أي واحد للانتقال إليه، أو **✓ close** لإغلاقه.

## الإعدادات
| الإعداد | المعنى |
|---|---|
| Ask when I open a tab | **Always** (دائماً) / **When many tabs are open** (افتراضي: عندما يكون عندك أكثر من 6) / **Never** (فقط بالاختصار) |
| Remind me when I return after | بعد كم دقيقة غياب يذكّرك |
| `Alt+Shift+W` | اكتب أو عدّل سبب التبويب الحالي في أي وقت |

## ملاحظات
- التبويب الذي تفتحه في الخلفية (Ctrl+نقر) يُسأل عنه **عندما تنظر إليه أول مرة**، لا لحظة فتحه.
- الأسباب تبقى حتى بعد إعادة تشغيل Chrome.
- الخفة: لا يوجد كود دائم داخل الصفحات. الشريط يُحقن فقط لحظة ظهوره.
