# 02 · Sleepy Tabs: تنويم التبويبات وحفظها

## ماذا تفعل؟
1. **تنويم تلقائي:** أي تبويب لم تنظر إليه منذ 30 دقيقة (قابلة للتغيير) يُنوَّم. يبقى في مكانه بعنوانه وأيقونته، لكن صفحته تُزال من الذاكرة (RAM). عندما تضغط عليه يُعاد تحميله.
2. **حفظ وإغلاق (مثل OneTab):** زر واحد يحفظ كل تبويبات النافذة في قائمة ويغلقها. التبويبات المحفوظة لا تستهلك أي ذاكرة، وتستطيع فتحها لاحقاً واحداً واحداً أو كلها.

## كيف تعمل؟
- تستخدم `chrome.tabs.discard`، وهي نفس الآلية التي يستخدمها Chrome في ميزة Memory Saver. لا توجد "صفحة بديلة" مثل إضافة The Great Suspender القديمة، فلا تضيع تبويباتك إذا حُذفت الإضافة.
- منبّه (`chrome.alarms`) يوقظ الإضافة **مرة في الدقيقة** لجزء من الثانية فقط.

## الاستخدام
| الخيار | المعنى |
|---|---|
| Sleep tabs unused for | بعد كم دقيقة يُنوَّم التبويب |
| Never sleep pinned tabs | التبويبات المثبتة 📌 لا تنام |
| Never sleep tabs playing sound | الموسيقى والفيديو لا يتوقفان |
| Never sleep this site | استثناء الموقع الحالي، مثلاً موقع فيه نموذج تكتبه |
| Sleep all other tabs now | تنويم فوري لكل التبويبات عدا الحالي |
| Save & close all tabs in this window | الحفظ والإغلاق |
| Open saved tabs | صفحة القوائم المحفوظة |

## تنبيه
التبويب النائم يُعاد تحميله عند فتحه، فـ**أي نص كتبته ولم تحفظه في نموذج قد يضيع**. استخدم "Never sleep this site" للمواقع التي تكتب فيها كثيراً.
