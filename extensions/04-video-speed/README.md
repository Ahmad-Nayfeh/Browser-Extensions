# 04 · Speedy: التحكم بسرعة الفيديو

## ماذا تفعل؟
تغيّر سرعة **أي فيديو HTML5** (YouTube و Udemy و Coursera و LinkedIn Learning ومواقع الأخبار…) من 0.07× إلى 16×، وتتذكر سرعتك المفضلة لكل فيديو جديد.

## الاختصارات (قابلة للتغيير من النافذة)
| المفتاح | الوظيفة |
|---|---|
| `S` | أبطأ (−0.1) |
| `D` | أسرع (+0.1) |
| `R` | رجوع إلى 1×، والضغط مرة أخرى يرجع للمفضلة |
| `G` | السرعة المفضلة مباشرة (الافتراضي 1.75×) |
| `Z` | رجوع 10 ثوان |
| `X` | تقدم 10 ثوان |
| `V` | إظهار / إخفاء مؤشر السرعة على الشاشة |

الاختصارات لا تعمل وأنت تكتب في حقل نص، ولا في الصفحات التي ليس فيها فيديو، فلا تتعارض مع الموقع.

## كيف تبقى خفيفة؟
لا تراقب الصفحة. تضيف 3 مستمعين للأحداث فقط (ضغطة زر، بدء تشغيل فيديو، تحميل فيديو) ولا تفعل شيئاً حتى يحدث أحدها.

## حدود
البث المباشر (Live) لا يمكن تسريعه، فهذا حد في المتصفح نفسه.
