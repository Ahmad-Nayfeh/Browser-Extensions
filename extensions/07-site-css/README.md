# 07 · Restyle: CSS خاص بك لأي موقع

## ماذا تفعل؟
تكتب CSS لأي موقع فيُطبَّق في كل زيارة. أمثلة:

```css
/* إخفاء شريط جانبي مزعج */
.sidebar, #right-rail { display: none }

/* تكبير الخط وتوسيع النص */
article { font-size: 19px; line-height: 1.7; max-width: 900px }

/* إخفاء عنصر حسب نصه البديل */
img[alt="banner"] { display: none }
```

## الاستخدام
1. افتح الموقع ← اضغط أيقونة Restyle.
2. اكتب CSS، **التغيير يظهر فوراً** ويُحفظ تلقائياً.
3. المفتاح أعلى النافذة يشغّل أو يوقف CSS هذا الموقع دون حذفه.
4. **All sites…** تفتح صفحة فيها:
   - **Global CSS:** CSS يطبَّق على **كل** المواقع.
   - كل مواقعك مع إمكانية التعديل والحذف.
   - **Export / Import:** نسخة احتياطية في ملف.

## كيف تعمل؟
عند فتح أي صفحة تضيف الإضافة الـ CSS بـ `origin: "USER"`، أي **بأولوية المستخدم**، فيتغلب على CSS الموقع حتى بدون `!important` في معظم الحالات. لا يوجد كود داخل الصفحة.

## نصيحة للتعلم
في أي موقع اضغط بالزر الأيمن على العنصر ← **Inspect** لترى اسم الـ class أو الـ id، ثم استخدمه هنا.
